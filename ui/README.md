# Yard Sloth: UI Subsystem

The `ui/` subsystem contains the React + TypeScript presentation layer for **Yard Sloth**.

## Directory Layout

```
ui/
├── assets/            # Static image assets and styles
│   ├── images/        # High-resolution garden photography and sloth mascot
│   └── index.css      # Design constitution styles & fonts
├── components/        # Reusable presentation components
│   ├── Header.tsx     # Top bar following Top Bar Contract
│   ├── FrostBanner.tsx # Evening freeze hazard notification bar
│   └── OpenSourceStoryModal.tsx # Python + MCP architecture explorer
├── pages/             # Route views
│   ├── TonightPage.tsx # Evening frost action plan & Open-Meteo forecast
│   ├── YardWalkPage.tsx # Photo capture, camera triggers & live agent trace
│   ├── ConfirmPlantsPage.tsx # Human-in-the-loop candidate confirmation
│   ├── CalendarPage.tsx # Month & list view care calendar + RFC 5545 ICS export
│   └── SetupPage.tsx   # ZIP code & hardiness zone calibration
├── shared/            # Shared utilities
│   ├── api.ts         # REST client connecting to Python server
│   └── types.ts       # Plant, Task, Alert, and Forecast TypeScript interfaces
├── App.tsx            # Root application shell
└── README.md          # UI documentation
```

## Features

- **Mobile-First & Desktop Adaptive**: Thumb navigation on smartphones and expansive 1440px multi-column layout on desktop.
- **Zero Static Stored Data**: Consumes endpoints served by the Python backend (`server/`).
- **Human-in-the-Loop Review**: Candidates generated by the Plant Census Agent can be confirmed, edited, or skipped with zero latency.
- **Direct ICS Export**: Syncs deterministic calendar tasks with Apple Calendar, Google Calendar, and Outlook.
